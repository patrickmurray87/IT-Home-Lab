# Getting Started

This section contains the initial setup and foundational work required before building the remainder of the IT Home Lab.

The projects in this folder establish the development environment, repository structure, and workflow used throughout the repository.

## Purpose

The goal of this section is to create a repeatable, well-documented environment for future labs and projects.

Rather than beginning immediately with networking or cybersecurity exercises, the lab was first organized to support consistent documentation, version control, and project management.

## Projects

- Repository creation
- GitHub Desktop installation
- Visual Studio Code configuration
- Markdown documentation
- Git workflow (Commit → Push → Publish)
- Repository organization
- Documentation standards

## Skills Practiced

- Git fundamentals
- GitHub repositories
- Version control
- Markdown
- VS Code
- Technical documentation
- Project organization

## Outcome

Completing the setup phase established the foundation for the remainder of the IT Home Lab.

Every project completed after this point follows the same workflow:

1. Plan the project
2. Build the lab
3. Troubleshoot issues
4. Document the implementation
5. Commit changes
6. Push to GitHub
7. Review the published documentation

This standardized workflow helps ensure every project is repeatable, well documented, and professionally presented.
