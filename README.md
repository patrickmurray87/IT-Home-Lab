This repository documents my journey as I build practical experience through virtualization, Linux, networking, systems administration, and cybersecurity projects.

## About This Repository

This repository serves as the central hub for my IT Home Lab.

Rather than simply studying certification material, every concept is reinforced through hands-on labs, troubleshooting exercises, virtual machines, and technical documentation.

Each project is designed to simulate the type of work performed by IT support specialists, systems administrators, and cybersecurity professionals.

My objective is to develop the technical knowledge, troubleshooting methodology, and documentation practices expected of an IT professional by building real-world projects and maintaining a documented home lab.

# Learning Philosophy

Every project in this repository follows the same workflow:

1. Learn the concept.
2. Build the lab.
3. Troubleshoot problems.
4. Document the process.
5. Reflect on lessons learned.
6. Publish the results.

The objective of this repository is not simply to complete labs, but to understand the underlying technologies, develop structured troubleshooting habits, and build a portfolio that demonstrates practical, hands-on IT experience.
