# IT-Home-Lab

Welcome!

This repository documents my journey from beginner to IT professional through hands-on labs focused on:

- Linux
- macOS
- Windows
- Networking
- Virtualization
- Cybersecurity
- Troubleshooting
- Home Lab Projects

## Goal

Build real-world technical skills by documenting every lab, challenge, and solution.

Rather than simply earning certifications, this repository serves as a record of practical experience and continuous learning.

Larger multi-day projects that combine multiple technologies.
